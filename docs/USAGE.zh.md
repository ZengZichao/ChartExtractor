## 1. 安装与启动

- **安装包安装（推荐）**：从 [GitHub Releases](https://github.com/ZengZichao/ChartExtractor/releases) 下载 macOS 安装包（`.dmg` 或 `.app`），将 ChartExtractor 拖入「应用程序」后启动。首次打开若提示来源未知，请右键点击应用并选择「打开」。
- **从源码构建**：

  ```bash
  npm install
  npm run package   # 生成 .app（位于 src-tauri/target/release/bundle/macos/）
  ```

  如需 DMG：`scripts/create-dmg.sh`（产物位于 `release/`）。

系统要求：macOS 10.15 及以上。

## 2. 界面导览

主窗口自上而下分为：

- **菜单栏**（文件 / 编辑 / 视图 / 工具 / 主题 / 帮助）：导入、工程、撤销重做、缩放、拾色、网格检测、快捷键说明、关于等。
- **流程向导**（导入 → 校准 → 取点 → 导出）：跟随当前步骤高亮提示。
- **左侧面板**：随步骤切换显示导入 / 标定 / 检测 / 导出参数。
- **中央画布**：显示图表，支持平移、缩放、加点、右键编辑。
- **右侧 / 底部数据表**：各数据集的坐标点列表，可直接编辑。
- **状态栏**：显示当前状态与提示信息。

## 3. 导入图表

支持三种方式：

1. **拖拽**：将图片或 PDF 文件拖入主窗口。
2. **菜单 / 快捷键**：「文件 → 导入图片/PDF…」或 `Cmd/Ctrl + O`。
3. **剪贴板粘贴**：截图后直接按 `Cmd/Ctrl + V` 粘贴。

说明：

- 支持常见位图格式与多页 PDF；PDF 默认渲染第 1 页，可切换页面导入（每页作为一个数据集）。
- 特大图片（> 4000px）会提示是否自动降采样，以提升流畅度。
- 导入新图表会清空当前标定与数据（可用 `Cmd+Z` 撤销导入），软件会弹窗确认。

## 4. 坐标标定

标定是把「像素位置」映射为「真实数值」的关键步骤：

1. 进入「校准」步骤，按提示依次在图上点击 **4 个已知坐标点**：Xmin、Xmax、Ymin、Ymax（点击轴上刻度线的交点最准确）。
2. 在面板中为每个点填入对应的真实数值。
3. 选择刻度类型：
   - **线性**：常规直角坐标轴。
   - **对数**：对数刻度轴，也支持**负对数**（如 pH、log10(1/T) 这类取值随轴递减的轴）。
4. 可选填写**轴名称与单位**，会随导出写入元信息。
5. 点击确认完成标定；之后如需修改，可重新进入标定步骤调整。

> 提示：4 个标定点请尽量选相距较远、刻度值清晰的参考点，精度更高。

## 5. 提取数据

### 5.1 手动取点

- **左键**点击画布添加数据点；
- **右键**点击已有点可删除或编辑其数值；
- 适合点数少、或自动检测失败的场景。

### 5.2 自动提取（推荐流程）

自动提取基于「颜色分割掩码」：先把你关心的曲线/散点从背景中抠出来（生成黑白掩码），再做检测。

1. **颜色分割**（工具菜单 → 拾色模式，或检测面板）：
   - 用**拾色器**在图上点选目标曲线 / 散点的颜色；
   - 选择模式：**前景匹配**（只保留接近所选颜色的像素，适合浅色 / 杂乱背景）或**背景排除**（排除接近所选颜色的像素）；
   - 调整阈值并勾选**实时预览**，边调边查看黑白掩码，直到目标清晰、背景干净。
2. **曲线自动追踪**（适合折线图 / 平滑曲线，一个 X 对应一个 Y）：
   - 参数：**X 步长**（取样列间距，越小点越密）、**Y 步长**（纵向搜索精细度）、**平滑插值**（勾选后曲线更顺滑）；
   - 点击「追踪曲线」，结果先以半透明点预览。
3. **散点自动检测**（适合散点图）：
   - 参数：色块**直径上下限**（可过滤图例底色等大面积色块）；
   - 点击「检测散点」，检测到的散点进入预览。
4. **预览确认**：检测结果显示在画布上，可选择**追加**（并入当前数据集）或**替换**当前数据集。

### 5.3 多曲线与分拣

- **多曲线分离提取**：同一张图里多条颜色不同的曲线，逐条选前景色 → 追踪，结果自动加入各自的新数据集。
- **散点按颜色分拣**：检测到的散点可按颜色自动聚类，每组分到独立数据集。

### 5.4 网格辅助

「工具 → 识别网格线（辅助预览）」可自动检测图表网格线，叠加显示在画布上，帮助你判断数据点落位。

## 6. 数据编辑与撤销 / 重做

- **数据表**：每个数据集为一张表，X / Y 数值可直接点击修改（支持撤销）。
- **撤销 / 重做**：`Cmd/Ctrl + Z` / `Shift + Cmd/Ctrl + Z`，覆盖加点、删点、导入、清空等操作。
- **删除最后一个点**：`Delete` 或「编辑 → 删除最后一个点」。
- **清空当前数据集**：「编辑 → 清空当前数据集」。
- **移除可疑点**：检测结果如混入噪点，可用「移除可疑点」一键剔除。

## 7. 批量提取

适合「同一坐标系的系列图」成批处理：

1. 先在单张图上完成**标定**（批量模式沿用当前标定参数）。
2. 打开批量提取面板：
   - **选择文件夹**：软件自动列出其中的图片文件；
   - **选择输出目录**：指定 CSV 导出位置；
   - 点击**开始批量**，软件逐张导入 → 按当前标定提取曲线 → 自动导出 CSV；期间显示进度，可随时**停止**。
3. 结束后显示成功 / 跳过统计；尺寸与标定图不一致的图片会被自动跳过。

> 全程纯本地运行，不上传任何数据。

## 8. 工程管理：保存 / 打开 / 自动保存 / 最近文件

- **保存工程**：`Cmd/Ctrl + S` 或「文件 → 保存工程…」，生成 `.prj` 工程文件（内含图表、标定、数据集与元信息）；重复保存时旧文件自动备份为 `.prj.bak`。
- **打开工程**：「文件 → 打开工程…」，或直接把 `.prj` 拖入窗口。
- **示例工程**：「文件 → 打开示例工程…」可载入内置示例，快速体验完整流程（会提示确认，避免覆盖当前数据）。
- **自动保存**：编辑过程中软件自动把会话写入应用数据目录；若程序意外退出，下次启动会询问是否**恢复上次会话**，保存 / 放弃后自动清理。
- **最近文件**：「文件 → 最近文件」快速重开最近打开的图表 / 工程（最多保留 20 条）。

## 9. 数据导出

进入「导出」步骤（或向导第 4 步），可选：

| 选项 | 说明 |
| --- | --- |
| **选择数据集** | 勾选要导出的数据集，可多选 |
| **X / Y 列名** | 自定义输出列名 |
| **多集合并** | **长表** `dataset,X,Y`（pandas 可直读）或**宽表**（按 X 对齐） |
| **编码** | UTF-8（推荐）/ GBK（老版 WPS 兼容，仅 CSV/文本类） |
| **小数精度** | 控制输出数值的小数位数 |
| **包含表头行** | 是否输出列名行 |
| **元信息注释行** | 在文件头部写入 `#` 注释（轴名、单位、来源等）；保持关闭时 `pandas.read_csv` 可直接解析（读取时用 `comment='#'` 即可保留并解析元信息） |

- **格式**：xlsx（每个数据集一个 Sheet）/ CSV / JSON（JSON 始终包含数据集元信息）。
- 导出前有**全量预览**（每集前 5 行），确认后点击「导出」选择保存位置。

## 10. 多标签页与多图对比

- 「+」新建标签页，可同时打开多张图表，独立保存各自的标定与数据集；
- 关闭有未保存修改的标签页时会二次确认；
- PDF 的不同页也可分别导入为不同数据集。

## 11. 主题与语言

- **语言**：界面顶栏右侧「中 / EN」一键切换，无需重启。
- **主题**：菜单「主题」可选 **跟随系统 / 浅色 / 深色**。

## 13. 常见问题（FAQ）

**Q1：曲线追踪不到任何点？**
检查颜色分割掩码：目标曲线在掩码里应显示为清晰的白色线条。重新拾色、调整阈值或切换前景 / 背景模式后再试。

**Q2：检测结果混入图例、坐标轴文字？**
调整散点检测的直径上限过滤大色块；或在掩码预览中收紧阈值；手动删除个别噪点。

**Q3：PDF 打不开或提示解析失败？**
个别加密 / 特殊编码的 PDF 可能无法解析，请将目标页导出为图片后再导入。

**Q4：大图操作卡顿？**
按提示允许自动降采样到 ≤ 4000px；降采样不影响标定与提取（以标定点像素为准）。

**Q5：CSV 用 Excel 打开中文乱码？**
导出时选择 **GBK** 编码（兼容老版 WPS / 部分 Excel），或使用支持 UTF-8 的表格软件。

**Q6：误关窗口，数据丢了？**
自动保存会保留上次会话，重新启动软件时选择「恢复」即可。

**Q7：软件会联网吗？**
不会。所有功能 100% 离线，CI 中有静态扫描强制保证 `src/` 不出现任何联网调用。

## 14. 隐私与安全说明

- 图像解析、标定、提取、导出全部在本机完成，**无遥测、无上传、无第三方请求**。
- 工程文件、自动保存、最近文件列表仅写入本机用户数据目录（`~/Library/Application Support/com.chartextractor/`）。
- 构建与发布脚本（`scripts/notarize.sh`）所需的一切凭据均通过环境变量传入，仓库中不含任何密钥。
